# Permanent Rules

- IMMUTABLE CONTENT LOCK: Never alter, rewrite, or delete factual business info, legal text, attorney credentials, contact details, addresses, phone numbers, or FAQ answers. Never remove, break, or degrade Google Map embeds or Google Review boxes.
- ANTI-FALSE-POSITIVE LAW: Never claim any test passed without running the real CLI command and printing its raw exit code and exact numeric score. Never weaken, skip, mock, or delete a failing test assertion to force a pass. Fix only production code.
- TOKEN EFFICIENCY LAW: Never dump minified files, lockfiles, `node_modules`, or raw multi-MB logs into context. Redirect verbose CLI output into `.audit-tmp/` and read only compact JSON failure summaries.
